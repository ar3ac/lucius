# Security Policy

## Supported Versions

We currently support the latest main branch of Lucius. Since this is an active project, we recommend always running the latest version using the `update.sh` script.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Lucius, please do NOT report it by opening a public GitHub issue. 

Instead, please send an email to Luca Marrazzo or contact via GitHub private vulnerability reporting (if enabled).

We will try to acknowledge your report within 48 hours, and we will work to patch the vulnerability as quickly as possible. Once the issue is resolved and pushed, it will be publicly disclosed to help users update their instances.
